# GeyserEdu
a Geyser fork that allows Minecraft: Education Edition clients to join Minecraft: Java Edition servers. Regular Bedrock Edition players can connect at the same time, for true crossplay across editions.

This project has been moved to CodeBerg and is available for downloading on our Website.
